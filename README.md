## Run locally

Requires Node.js 20.9 or newer.

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

Verify a production build with:

```bash
npm run build
npm start
```

> The production build downloads the configured Geist fonts from Google Fonts,
> so the build environment needs outbound network access.
